# Компьютер хяналтын систем (Veyon-маягийн)

Windows дээрх нэг **controller** машинаас, дотоод сүлжээн дэх бүх **Ubuntu 24.04**
компьютерийг IPv4-ээр удирдах хэрэгсэл. Багш/админ өөрийн эзэмшлийн лаборатори,
ангийн компьютеруудыг хянах зорилготой.

## Боломжууд
- 🔍 Сүлжээг **scan** хийж agent суусан машинуудыг автоматаар олно
- 🖥️ Бүх машины **дэлгэцийг** grid-ээр шууд харах (автомат шинэчлэлттэй)
- ⌨️ Бүх/сонгосон машин дээр **terminal команд зэрэг ажиллуулж** гаралтыг харах
- 🖳 Тухайн нэг машин руу **интерактив terminal (амьд shell)** нээж харьцах (cd, top, nano г.м)
- ⏻ Сонгосон буюу **бүх машиныг зэрэг унтраах / reboot**
- 🔒 Дэлгэц **түгжих**
- 💬 Хэрэглэгчид **мессеж** илгээх
- 🔑 Бүх холболт **токеноор** хамгаалагдсан

## 1. Ubuntu машин бүр дээр agent суулгах

`agent/` хавтсыг тухайн машин руу хуулаад (USB, scp, эсвэл git):

```bash
sudo ./install.sh <ТОКЕН> [ПОРТ]
# Жишээ:
sudo ./install.sh MyLabSecret2024
```

- `<ТОКЕН>` — өөрийн сонгосон нууц түлхүүр. **Бүх машин болон controller дээр ижил** байна.
- Порт өгөхгүй бол `8765` ашиглана.

Скрипт нь шаардлагатай багцуудыг (gnome-screenshot, scrot гэх мэт) суулгаж,
`systemd` service болгон enable хийж, машины IP хаягийг хэвлэнэ.

Дараа нь шалгах:
```bash
systemctl status monitoring-agent
```

> **Санамж:** Ubuntu 24.04 нь GNOME/Wayland ашигладаг. `gnome-screenshot` энэ дээр
> ажиллана. Хэрэв дэлгэцийн зураг гарахгүй бол тухайн машин дээр хэрэглэгч
> график session-д нэвтэрсэн эсэхийг шалгана уу (нэвтрээгүй үед дэлгэц байхгүй).

## 2. Windows дээр controller ажиллуулах

```bash
cd controller
pip install -r requirements.txt
copy config.example.json config.json
```

`config.json`-г нээж засна:
- `token` — agent-уудтай **ижил** түлхүүр
- `subnets` — scan хийх сүлжээ. Лабораторийн сүлжээ 192.168.0.x бол `"192.168.0.0/24"`.
  Өөрийн IP-г мэдэхийн тулд Windows дээр `ipconfig` ажиллуулж, IPv4 хаягаа хар.

Дараа нь:
```bash
python controller.py
```

Browser дээр нээх: **http://127.0.0.1:5000**

**Scan хийх** товчийг дарж машинуудаа олоод, дэлгэц дээр дарж томруулж харах,
эсвэл сонгоод унтраах/reboot/түгжих командууд өгнө.

## Аюулгүй байдал / Тэмдэглэл
- Токен нь энгийн хамгаалалт. Итгэлтэй **дотоод** сүлжээнд ашиглах зориулалттай —
  интернэтэд шууд ил гаргаж болохгүй.
- Агент нь `root` эрхээр ажилладаг (унтраах/reboot хийхэд шаардлагатай).
- Windows-ийн галт хана controller-ийн гарах холболтыг хаахгүй байх ёстой (ихэвчлэн асуудалгүй).
- Ubuntu талд `ufw` идэвхтэй бол install.sh нь портыг автоматаар нээнэ.

## Асуудал шийдвэрлэх
| Шинж тэмдэг | Шалгах зүйл |
|---|---|
| Scan-д юу ч олдохгүй | `subnets` зөв эсэх, agent ажиллаж байгаа эсэх (`systemctl status`), порт нээлттэй эсэх |
| "token таарахгүй" | controller болон agent-ийн `token` ижил эсэх |
| Дэлгэц хоосон/алга | Хэрэглэгч нэвтэрсэн эсэх; `gnome-screenshot` суусан эсэх |
| Унтраахгүй байх | agent `root`-оор ажиллаж байгаа эсэх (`systemctl status monitoring-agent`) |
